# 图片与 PDF 合并工具

> 基于 Tauri 和 Vue 3 开发的桌面应用程序，用于将多张图片合并为 PDF 文件，也可用于日常资料整理。

## 技术栈

- **前端框架**：Vue 3 + Vite
- **UI 组件库**：Element Plus
- **桌面应用框架**：Tauri 2.0
- **PDF 处理**：jsPDF
- **看板娘**：OhMyLive2D
