# 提示词与使用方法

Prompt 不需要写得很玄学，关键是把背景、目标、限制和输出格式说清楚。

## 通用结构

```text
你是：说明角色或任务类型
背景：说明项目、场景、当前问题
目标：说明希望完成什么
限制：说明不能做什么、要遵守什么规则
输出：说明希望得到列表、表格、步骤还是代码
```

## 代码修改类

```text
请先阅读这个项目的结构，然后帮我修改 XX 功能。
要求：
1. 不要改无关文件。
2. 保持现有代码风格。
3. 修改后说明改了哪些文件。
4. 如果不能验证，请告诉我原因和验证方式。
```

## 报错排查类

```text
我遇到了这个报错：
【粘贴完整报错】

环境：
- 系统：Windows / Linux / macOS
- Node 版本：
- 框架版本：
- 操作步骤：

请帮我分析可能原因，并按优先级给出排查步骤。
```

## 文档整理类

```text
请把下面内容整理成适合放进技术博客的文章。
要求：
- 标题清晰
- 保留关键命令和代码块
- 说明问题现象、原因分析、解决方法
- 最后增加注意事项
```

## 使用原则

- 先让 AI 理解上下文，再让它动手。
- 一次只交代一个明确目标，避免任务过大。
- 对代码、命令、配置文件要自己复核，尤其是删除、部署和密钥相关操作。
- 对版本、价格、模型名等实时信息，优先查看官方文档。
