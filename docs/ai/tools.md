# 常用 AI 工具清单

这里整理一些适合日常开发、写作、学习和资料处理的 AI 工具。后续可以按使用体验继续补充。

## 编程助手

| 工具 | 适合场景 | 备注 |
| --- | --- | --- |
| Claude Code | 终端内代码理解、修改、重构和项目协作 | 适合真实代码仓库操作。 |
| GitHub Copilot | IDE 内代码补全和对话 | 适合日常编码辅助。 |
| Cursor | AI IDE、代码问答和项目级编辑 | 适合前端和全栈项目开发。 |
| OpenCode | 终端 AI 编程助手 | 可接入多种模型供应商。 |

## 通用对话与知识整理

| 工具 | 适合场景 | 备注 |
| --- | --- | --- |
| ChatGPT | 问答、写作、代码、方案设计 | 综合能力强。 |

## 我的使用建议

- 写代码：优先让 AI 先读项目结构，再给出改动计划。
- 写文档：先给目标读者和目录，再让 AI 分段生成。
- 查问题：提供报错、环境版本、复现步骤，不要只贴一句错误。
- 做方案：要求 AI 给出优缺点、风险和备选方案。
